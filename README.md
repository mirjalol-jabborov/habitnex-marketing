# Habitnex marketing

Material for promoting Habitnex.

| Folder | What |
| --- | --- |
| [`product-video/`](product-video/) | The 40-second vertical product video, rendered from code, with its narration, music and tools. See [product-video/README.md](product-video/README.md). |
| [`app-store/`](app-store/) | The six App Store screenshots, made from real captures of the app, and the scripts that remake them. See [app-store/README.md](app-store/README.md). |

Keys (for example the ElevenLabs key in `product-video/.env`) are never committed.
